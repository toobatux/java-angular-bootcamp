
| File | Destination |
| ---- | ----------- |
| `Customer.java` | src/main/java/com/example/... |
| `CustomerServiceTest.java` | src/test/java/... |
| `application.properties` | src/main/resources/ |
| `sample-customers.json` used only by tests | src/test/resources/ |
| `CODING-STANDARDS.md` | docs/ |
| `Customer.class` | generated under target/classes/ |


The target folder is generated from the source code, so it should be ignored and not committed

Do not put production java in the tests directory, put it in main instead. Tools like maven compile src/main/java
Do not commit secrets to application properties. Exposes secrets and brings major risks to security
Do not hand edit the target directory, as it's generated by maven
Placing test files inside resources means that it gets packaged into your production JAR file
Unnecessarily bloats final deployment size
